What started in 2019 as a few containers on a Raspberry Pi is now a beefy home server running over 40 self-hosted services, including Home Assistant, Immich, Paperless, WireGuard and Vaultwarden.

It is my playground for the same practices I apply at work: everything is defined as code, deployed through GitOps, and secured, monitored and backed up as if it were production. It has taught me to build infrastructure that maintains itself, and helps to try out new tools before I recommend them to a team.
